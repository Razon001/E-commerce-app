# E-commerce-app

# TOGO The app
> An ecommerce app where you sell or  purchase your favourite items. You can create your own account and personalize
## 🚀 Features
* **Key Feature 1:** Free Account creation and verification.
* **Key Feature 2:** Upload your selling Item personalize them add price and attract customer.
* **Key Feature 3:** Purchase your item and payment system.

## 🛠️ Tech Stack
* **Frontend:** [ XML, Java]
* **Backend:** [ Java]
* **Database:** [ Firebase ]
